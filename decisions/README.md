# Decisions

Architecture decision records for brignano.io: one file per decision,
`NNNN-slug.md`, numbered in date order. A decision is never edited after it
merges except to mark it superseded; a change of mind is a new record.

Design-system decisions (colour, type, components) live in brignano/design,
not here.

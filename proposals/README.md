# Proposals

Designs and plans for brignano.io, written before the work. Each file opens
with a `Status:` line: proposed, accepted, building, shipped, parked or
rejected. Wireframes for UI changes live in [`wireframes/`](wireframes/README.md).
Decisions that outlive a proposal are recorded in [`decisions/`](../decisions/README.md).

The fleet standard for proposals and decisions is in brignano/ai-tools
[`fleet/README.md`](https://github.com/brignano/ai-tools/blob/main/fleet/README.md).
